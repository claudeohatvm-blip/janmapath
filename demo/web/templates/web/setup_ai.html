What the AI does, and does not do

Every number in your reading is computed by the Vedic engine: planetary longitudes from the Swiss Ephemeris, houses, divisional charts, Vimshottari dasha, yogas, doshas and the domain scores. That code imports no network library at all — it cannot call a model even if asked to.

Computed by the engine Planetary positions, ascendant, houses, D9 and D10, dasha periods, yogas, doshas, strength scores, every band and verdict
Written by rules The full report prose, in English — always, with no API key
Optionally rewritten by AI Wording only, for fluency and for other languages
Never touched by AI Any placement, score, band or conclusion

The model receives the findings and the rule-written draft, and is constrained to narrate only what it is given. If it is unreachable the report silently keeps the rule-written text.

Getting an API key

  1. Create an Anthropic account

    Go to console.anthropic.com and sign up, or sign in if you already have an account. This is the developer console, which is separate from a Claude.ai chat subscription — a Claude Pro plan does not include API access.

  2. Add credit

    Open Billing (or Plans & Billing) and purchase credit. The API is prepaid; a new account typically needs a minimum first purchase. Without credit, every request fails with a credit_balance_too_low error.

  3. Create the key

    Go to API Keys, click Create Key, and give it a name such as janmapath-demo. Copy it immediately — the full key is shown only once. It begins with sk-ant-.

  4. Set a spend limit

    Still in the console, set a monthly spend limit before you start. This is the single most useful safeguard against a runaway loop during development.

Configuring this app

1. Install the SDK

pip install anthropic

2. Provide the key

The app reads ANTHROPIC_API_KEY from the environment. Either export it…

# macOS / Linux
export ANTHROPIC_API_KEY="sk-ant-..."

# Windows PowerShell
$env:ANTHROPIC_API_KEY = "sk-ant-..."

…or put it in a .env file beside manage.py, which the app loads on start:

ANTHROPIC_API_KEY=sk-ant-...

Never commit the key. .env is already listed in .gitignore. A key pushed to a public repository is scraped within minutes; if that happens, revoke it in the console immediately.

3. Restart and verify

python demo/manage.py runserver

Reload this page. The status panel above should show the SDK installed and the key detected. The narration toggle then appears on the reading form.

What it costs

The app uses {{ ai.model }}. One reading sends roughly 4,000 input tokens (the findings plus the draft) and receives about 2,500 output tokens — on current pricing, on the order of 8 US cents per report.

At production scale the daily-horoscope pipeline is the cost that matters, not reports. Narration there is generated per signature group rather than per user and cached, which is what keeps it affordable — see docs/ARCHITECTURE.md.

Troubleshooting

Page still says “not set” The variable was exported in a different shell from the one running the server, or the server was not restarted. Environment variables are read once at process start.
authentication_error The key is wrong, revoked, or has stray whitespace or quotes. Create a fresh key and paste it without surrounding quotes in .env.
credit_balance_too_low The account has no credit. Add credit under Billing.
rate_limit_error Too many requests for the account tier. Wait and retry; limits rise automatically with usage history.
Report appears but reads like the rules version Narration failed and fell back silently by design — the report is never blocked on the model. Check the server console for a AI narration unavailable warning with the reason.
Using a different provider Replace apps/reports/narrator_ai.py. It has one entry point, narrate(report, findings, language), and returns the report unchanged on any failure. Nothing else in the codebase talks to a model.
