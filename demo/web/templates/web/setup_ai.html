What the AI does, and does not do

Every number in your reading is computed by the Vedic engine: planetary longitudes from the Swiss Ephemeris, houses, divisional charts, Vimshottari dasha, yogas, doshas and the domain scores. That code imports no network library at all — it cannot call a model even if asked to.

Computed by the engine Planetary positions, ascendant, houses, D9 and D10, dasha periods, yogas, doshas, strength scores, every band and verdict
Written by rules The full report prose, in English — always, with no API key
Optionally rewritten by AI Wording only, for fluency and for other languages
Never touched by AI Any placement, score, band or conclusion

If the model is unreachable the report silently keeps the rule-written text. Generation is never blocked on it.

Google Gemini — via AI Studio

Free tier, and no payment card required to start. The quickest option for testing.

  1. Open AI Studio

    Go to aistudio.google.com/apikey and sign in with a Google account.

  2. Create the key

    Click Create API key. Copy it immediately.

    Keys come in two formats and both are valid: AQ.... is the current format, AIza... the legacy one. If another tool rejects an AQ. key, that tool has a hardcoded AIza check — not a problem with your key. This app accepts both.

  3. Install the SDK

    pip install google-genai

  4. Set the key

    # macOS / Linux
export GEMINI_API_KEY="AQ...."

# Windows PowerShell
$env:GEMINI_API_KEY = "AQ...."

    Or add it to .env beside manage.py:

    GEMINI_API_KEY=AQ....
# optional, default is gemini-2.5-flash
GEMINI_MODEL=gemini-2.5-pro

Anthropic Claude

Prepaid credit required. A Claude.ai chat subscription does not include API access.

  1. Create an account

    console.anthropic.com — the developer console, separate from Claude.ai.

  2. Add credit and a spend limit

    Under Billing. Without credit, requests fail with credit_balance_too_low. Set a monthly spend limit while you are there — the best safeguard against a runaway loop.

  3. Create the key

    API Keys → Create Key. Shown only once; it begins sk-ant-.

  4. Install and configure

    pip install anthropic
export ANTHROPIC_API_KEY="sk-ant-..."

Then restart

python demo/manage.py serve

Environment variables are read once at process start, so a running server will not pick up a new key. Reload this page afterwards — the provider panel above should show the key detected.

Never commit a key. .env is already in .gitignore. A key pasted into a chat, an issue, or a public repository should be treated as compromised and rotated immediately — scrapers find them within minutes.

Troubleshooting

Panel still says “not set” The variable was exported in a different shell from the one running the server, or the server was not restarted.
Gemini: 401 UNAUTHENTICATED Key is wrong, revoked, or has stray quotes or whitespace. Create a fresh one in AI Studio.
Gemini: 429 RESOURCE_EXHAUSTED Free-tier rate limit. Wait a minute, or switch model with GEMINI_MODEL.
Gemini: empty response Usually a safety block or an exhausted output budget. The server log names the finish reason.
Claude: authentication_error Key wrong or revoked. Create a fresh one.
Claude: credit_balance_too_low No credit on the account.
Report reads like the rules version Narration failed and fell back by design. The server console carries an AI narration unavailable warning naming the reason.
Adding another provider Drop a module into apps/reports/providers/ with status() and narrate(payload, language), and register it in narrator_ai.PROVIDERS. Nothing else in the codebase talks to a model.
